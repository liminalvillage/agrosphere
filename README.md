# AgroSphere SHIFT

Product website for SHIFT (Small Holding Integrated Farming Technologies), AgroSphere's integrated set of bed-farming machines, with Holons as the coordination platform.

Static site, no build step. Everything is in `site/`:

- `site/index.html` – the single page
- `site/images/` – photographs from the SHIFT catalogue, plus the Holons logo and map

Open `site/index.html` in a browser to preview. Netlify publishes the `site` folder (see `netlify.toml`).
